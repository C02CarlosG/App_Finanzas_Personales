# Logos de bancos

Coloca aquí el logo de cada banco como `<logo_key>.png` (la clave la define el catálogo del servidor:
`bbva`, `santander`, `banamex`, `banorte`, `hsbc`, `scotiabank`, `inbursa`, `azteca`, `bancoppel`, `afirme`,
`banregio`, `nu`, `hey`, `mercadopago`, `klar`, `spin`).

La app usa el archivo si existe; si no, muestra un avatar con las iniciales y el color del banco.
Respeta las condiciones de uso de marca de cada institución al agregar logos.
